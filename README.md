# Web_Crawler_Eleicao_2026
O aluno deverá propor melhorias e aplicar correções.

## Diagnóstico inicial

O programa foi executado e apresentou as tabelas sem erro.

Pontos que precisam de melhoria:
- Consulta apenas um município por execução.
- Não oferece seleção explícita entre primeiro e segundo turno.
- Não identifica os candidatos eleitos.

## Melhorias planejadas

- Consultar todos os municípios do Maranhão.
- Permitir consultas separadas por turno, quando houver dados.
- Identificar os eleitos pela situação oficial dos candidatos.
- Melhorar a organização do código e as mensagens de erro.
